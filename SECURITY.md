# Security Policy

## Supported versions

Only the latest version on the `main` branch and the current production deployment are actively supported with security fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Report them privately to the ARICT administrators through the contact details on [arict.lk](https://arict.lk/contact), and include:

- A clear description of the vulnerability and its potential impact.
- Steps to reproduce the issue or a proof of concept.
- Affected URLs, files, versions, or configurations.
- Any suggested mitigation.

Please avoid including real user data, credentials, or other secrets in a report. We will acknowledge reports as soon as practical, investigate them, and coordinate disclosure and remediation with the reporter.

## Security expectations for contributors

Never commit credentials, API keys, `.env` files, production data, or private user information. Review changes involving authentication, authorization, uploads, forms, database access, and environment variables carefully before opening a pull request.
